Privacy Policy

Last updated: October 28, 2026

What this app is

NuxClipss Uploader is a private, internal tool used only by the owner of the YouTube channel NuxClipss (https://www.youtube.com/channel/UCEWz15WWaW2pYf2GCKUAWFA). It runs on the owner's own computer. It is not offered to the public and has no other users.

Data it accesses

With the owner's permission, granted through Google's sign-in, the app uses the YouTube Data API to upload videos to the owner's channel and to update details of the owner's own videos. It also reads the owner's own channel statistics (read-only, through the YouTube Analytics API) so the owner can track watch time on their own channel. It accesses only the owner's own YouTube account.

How data is stored

The sign-in token is stored only on the owner's computer, in a file only that account can read. Videos and their details come from the owner's own files. No data is sent to any server other than Google's.

Data sharing

The app does not sell, share or transfer any user data to third parties. It does not use YouTube data for advertising or profiling.

Retention and deletion

The owner can revoke the app's access at any time at https://myaccount.google.com/permissions. Deleting the token file from the owner's computer removes all stored credentials.

YouTube and Google

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
