NuxClipss Uploader

NuxClipss Uploader is a private tool used only by the owner of the YouTube channel NuxClipss. It runs on the owner's own computer and uses the YouTube Data API to upload the owner's edited videos, set their titles, descriptions, tags, thumbnails and playlists, and schedule when they publish. It also reads the owner's own channel statistics (read-only, YouTube Analytics API) to track watch time.

It is not offered to the public and has no other users.
